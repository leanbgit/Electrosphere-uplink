Game data

Checking…

The game (about 1.4 GB) is kept in this browser's own storage while you play, so later sessions do not download it again. It is not saved as a file on your computer.

Play online together

Each player on their own computer. The host's memory card and settings are used, and nothing is saved on the guest's side. The guest flies as the second plane.

      Controls

      Click a key to change it, then press the new key (Esc cancels). Your keys are remembered in this browser. Any standard game controller works too: press a button on it once the game is running.

      About

      A free, non-commercial fan project: the game's own program runs on a recreation of the PlayStation's system libraries compiled for the web.

      The English text is Project NEMO's fan translation (v0.9b3). Your saves, settings and the downloaded game data stay in this browser on this computer.
